# Pathfinder 1e Obsidian Campaign Vault

A lightweight, shareable Obsidian vault template for Pathfinder 1st Edition players to capture session notes, NPCs, PCs, monsters, universal monster rules, and locations across a full Adventure Path.

## Getting Started

1. **Download or clone this repository:**
   - **Non-technical:** Click **Code → Download ZIP** and unzip it somewhere permanent (e.g., `Documents/TTRPGNotes`).
   - **Git users:** `git clone <repo-url>`
2. Open **Obsidian** → **Open folder as vault** → select the `TTRPGNotes` folder.
3. When prompted **"Do you trust the author of this vault?"**, click **Trust author and enable plugins**.
4. The vault will open to `Campaign-Vault/Dashboard.md` in Reading View. Follow the **New to this vault?** banner at the top to explore `00-Start Here/` and set up your campaign.

## Included Plugins
- **Dataview** — Powers the Campaign Dashboard tables and unresolved plot-thread checklist.
- **Templater** — Auto-applies templates per folder and provides quick-insert templates via the Command Palette (`Ctrl/Cmd + P` → *Templater*).
- **Auto Note Mover** — Automatically files tagged notes into the right `Campaign-Vault/` folders.
- **Homepage** — Opens `Campaign-Vault/Dashboard.md` in Reading View on startup.
